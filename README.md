# Angelo Gaona — Portafolio

¡Hola! 👋 Soy **Angelo Gaona** (_Tensangelo_), desarrollador **full stack** enfocado en front-end con pasión por las interfaces de usuario, las animaciones y las herramientas creativas y dinámicas.

Este es mi **portafolio personal**: una carta de presentación que refleja mi recorrido, las tecnologías con las que trabajo y algunos de los desarrollos que he construido.

## ✨ Funcionalidades

- **Landing** con animaciones (nieve, neón y efectos personalizados).
- **Acerca de mí**: breve introducción y stack de tecnologías.
- **Desarrollos**: proyectos reales con enlace a sus versiones en vivo y repositorios.
- **Extras**: un vistazo a animaciones y experimentos.
- **Resumen (CV)** descargable en formato PDF.

## 🛠️ Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router) + React
- **Lenguaje**: TypeScript
- **Estilos**: Sass (módulos SCSS)
- **Iconos**: Material Design Icons
- **Despliegue**: Vercel
- **Gestor de paquetes**: pnpm

## 🚀 Puesta en marcha

```bash
# Instalar dependencias
pnpm install

# Servidor de desarrollo
pnpm dev

# Compilación de producción
pnpm build

# Iniciar servidor de producción
pnpm start

# Lint
pnpm lint

# Verificación de tipos
pnpm typecheck
```

Abre [http://localhost:3000](http://localhost:3000) para ver el proyecto en tu navegador.
